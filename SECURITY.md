# Security policy

These repositories are defensive educational utilities. Please do not include live targets, credentials, tokens, private keys, personal data, or exploit code in an issue or pull request.

## Reporting a vulnerability

If you find a security issue in the code, open a private security advisory on GitHub when available or contact the repository owner through the GitHub profile. Include a minimal reproducible example using sanitized local input. Do not test against systems you do not own or have explicit permission to assess.

## Scope

The tools intentionally avoid credential attacks, payload execution, persistence, evasion, process injection, port scanning, exploitation automation, and covert communication. Reports that request or demonstrate those capabilities are out of scope.
